# Workday Copilot

Build a modern, responsive SaaS web app called AI Workplace Productivity Assistant to help professionals automate workplace tasks using genuinely AI-generated responses.

DESIGN & DASHBOARD
Use dusty pink #E8A0BF, dark navy #25212B, and white. Create a clean, polished, professional interface with a sidebar, top navigation, welcome message, profile icon, productivity overview cards, quick actions, recent activity, rounded cards, and responsive desktop/mobile layouts.

NAVIGATION: Dashboard, Smart Email Generator, Meeting Notes, AI Chatbot, Settings.

FEATURES

Smart Email Generator: Inputs for recipient, purpose, and key details; Formal, Friendly, and Persuasive tones; generate editable, context-specific professional emails with copy buttons.

Meeting Notes: Accept lengthy pasted notes; AI-generated summaries identifying key points, decisions, action items, owners, and deadlines. Outputs must be editable and copyable.

AI Workplace Chatbot: Interactive chat interface that responds intelligently and contextually to user prompts about workplace tasks.

REQUIREMENTS: Genuine AI-generated, non-generic responses; structured AI prompts; editable outputs; copy functionality; loading and error states; responsible AI disclaimer; professional UX; fully responsive design.

TECHNICAL: Frontend only; no custom backend or database. Use a supported AI integration if available without building a backend. Never simulate AI with fixed responses or claim AI works when it does not. If AI requires external configuration or an API key, clearly explain this limitation. Build the complete functional frontend and all three feature interfaces. Keep the implementation simple and avoid unnecessary features.
