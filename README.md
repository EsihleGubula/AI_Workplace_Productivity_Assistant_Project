# AI Workplace Productivity Assistant

## 1. Project Overview

The AI Workplace Productivity Assistant is a web application designed to help users complete common workplace tasks more efficiently using artificial intelligence. It provides tools for generating professional emails, summarising meeting notes, identifying action items, and receiving assistance through an interactive AI chatbot.

The application was built using Lovable and is maintained in GitHub.

## 2. Features Implemented

### Smart Email Generator
- Generates professional emails based on user-provided details.
- Offers three tones: Formal, Friendly, and Persuasive.
- Allows users to review and edit generated content.

### Meeting Notes
- Summarises meeting notes.
- Identifies key decisions and action items.
- Helps organise responsibilities and deadlines.

### AI Chatbot
- Provides interactive assistance with workplace-related questions and tasks.
- Supports follow-up questions.
- Helps users organise tasks and find solutions to everyday workplace challenges.

### Dashboard
- Provides access to the application's main features.
- Includes sidebar navigation.
- Offers a structured and user-friendly interface.

## 3. Design and User Interface

The application uses a clean, modern dashboard design with a dusty pink, dark navy, and white colour palette.

- Dusty pink: `#E8A0BF`
- Dark navy: `#25212B`
- White: `#FFFFFF`

The interface is designed to be easy to navigate and responsive across different screen sizes.

## 6. How to Use the Application

1. Open the [AI Workplace Productivity Assistant](https://ai-workplace-assistance.lovable.app) in a web browser.
2. Navigate through the dashboard using the sidebar menu.
3. **Smart Email Generator:** Enter the details of the email you want to write, select a preferred tone, and generate your email. Review and edit the result before using it.
4. **Meeting Notes:** Enter your meeting notes and generate a summary. Review the key decisions, action items, responsibilities, and deadlines.
5. **AI Chatbot:** Enter a workplace-related question or task to receive assistance. Ask follow-up questions when you need more specific information.
6. Review AI-generated content carefully and correct any errors before using or sharing it.

## 7. Setup Instructions

### Prerequisites

- A computer with an internet connection.
- A web browser.
- Git, if you want to clone the repository using the command line.

### Access the Live Application

1. Visit https://ai-workplace-assistance.lovable.app.
2. Use the dashboard to access the available productivity tools.

### Access the Source Code

1. Visit the [GitHub repository](https://github.com/EsihleGubula/AI_Workplace_Productivity_Assistant_Project).

3. To download a copy, select **Code** and then **Download ZIP**.

To run the project locally, download or clone the repository and follow the installation and startup instructions supported by the project's configuration files. The exact commands depend on the files and dependencies included in the repository.

## 8. Responsible AI

The application includes a disclaimer reminding users that AI-generated information may contain errors. Users should review, verify, and edit generated content before relying on it or sharing it with others.
